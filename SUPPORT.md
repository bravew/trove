Use [GitHub Discussions](https://github.com/bravew/trove/discussions) for
usage questions, ideas, and general discussion.

## Report a bug

Use [GitHub Issues](https://github.com/bravew/trove/issues). Include:

- Your host (Claude Code, Cursor, Codex, etc.) and its version
- The command or plugin/skill involved
- Expected vs. actual behavior
- `./bin/trove doctor` output if relevant

## Report a security issue

See [SECURITY.md](SECURITY.md) — do not open a public issue.
