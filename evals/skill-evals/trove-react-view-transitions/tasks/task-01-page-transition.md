# Task: Add a fade-and-slide page transition

Add a smooth fade-and-slide transition between two routes in a Next.js App Router app using the View Transition API. Implement the trigger via `startViewTransition`, define `::view-transition-old(root)` and `::view-transition-new(root)` keyframes, and ensure the transition does not run on the initial page load. Explain how you handled browsers that lack View Transition support.
